# Dashboard

Interface dédiée à l’affichage des informations clés du projet.  
Contient la structure HTML, le style visuel et la logique JavaScript.

## Contenu
- [x] **index.html** — Page principale du tableau de bord  
- [x] **style.css** — Mise en forme et thème visuel  
- [x] **app.js** — Logique, interactions et chargement des données

## Objectif
Fournir un tableau de bord simple, rapide et fonctionnel pour visualiser l’état du système.

## Utilisation
Ouvrir `index.html` dans un navigateur pour lancer le dashboard.
